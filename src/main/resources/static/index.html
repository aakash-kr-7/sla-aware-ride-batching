Timing and retries

Requests use the server's current 15-minute UTC window. The local profile allows immediate batching. Pickup deadlines still apply. Repeating the same employee and journey in the same window returns the existing booking. A failed or timed-out request is not retried automatically; check the request log before sending again.

Local setup and reset

Start PostgreSQL, then the application from the repository root: 

docker compose -f compose.local.yml up -d --wait

# PowerShell
.\mvnw.cmd spring-boot:run '-Dspring-boot.run.profiles=local-fixtures'

# Linux / macOS
./mvnw spring-boot:run -Dspring-boot.run.profiles=local-fixtures

For a fresh run, stop the app first, remove the disposable local database with docker compose -f compose.local.yml down --volumes , then start it again. Signing out clears the browser session and leaves saved rides intact.
